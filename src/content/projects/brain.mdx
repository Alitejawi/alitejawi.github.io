## Problem

I save a lot: articles, research papers, case studies, talks and videos. Saving was easy. Finding the right thing again weeks later was not. Bookmarks pile up, titles don't say what's inside, and a lot of the useful content is spoken in a video or written on a slide, where search can't reach it.

## What I built

A pipeline that reads what I save, so I don't have to remember where I saw it.

- **Takes in** articles, research papers, case studies, videos and posts.
- **Reads what search can't:** speech is transcribed on the Mac with Whisper, and text on slides is read with Apple Vision.
- **Local models** (Ollama) write a summary and tags for every save with enough text to summarise.
- **`/ask`** answers a question from my saved notes, and cites the sources it used.

## How I measured it

Search quality is measured against a fixed set of 50 test queries, so every change is compared on the same questions. A local model wrote each query from a saved note, as a stand-in for how I would half-remember it. It is not a study of real searches.

| Metric | Before | After |
|---|---|---|
| hit@5 (the right note in the top 5) | 42% | 66% |

The jump came from a rebuilt search: keyword search (BM25) combined with vector search, a new embedding model, and notes split into passages. I haven't measured each part on its own.

## Guardrails

- **No summary from too little text.** If a source has fewer than 400 characters of text, Brain skips the AI summary instead of guessing.
- **Missing saves raise an alert.** A daily check compares what I saved with what arrived, and alerts my phone about anything missing.

## What I changed after launch

Brain started on n8n in April 2026. In June, a hardening change to the SSH bridge between n8n and the host machine began rejecting every pipeline command. n8n recorded each failure as data, so 676 runs were marked success while writing nothing. For ten weeks no saved link reached Brain, and all eight of my watchdog checks passed.

The checks were testing stand-ins for success: a job ran, a binary existed, an exit code came back. None of them tested the outcome. I replaced them with checks on what actually arrived, then rebuilt the pipeline as a tested Python package and retired n8n on 4 September 2026. Today the package has 1,476 tests.
